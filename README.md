# Invitación XV años de Karen

Proyecto base de la invitación digital, creado con Next.js, React, TypeScript y Tailwind CSS.

## Desarrollo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en el navegador.

## Verificaciones

```bash
npm run lint
npm run build
```

La configuración de npm conserva compatibilidad con `react-spring-lightbox`, cuya declaración de peer dependencies corresponde a versiones anteriores de React.
